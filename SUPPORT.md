# Support

## Getting help

- Open a Bug report for a reproducible website or build problem.
- Open a Feature request for a focused improvement.
- For setup issues, include your Node.js version, operating system, command, and exact error.

Check the README and existing issues first. For visual defects, include browser, viewport size, and screenshots.

Do not post credentials, private client assets, personal information, or unredacted logs. For security concerns, follow SECURITY.md. Support is provided on a best-effort basis.
