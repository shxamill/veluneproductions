# Contributing

This repository contains the Velune Creative Studio website built with Astro.

## Local setup

Requirements: Node.js 22.12 or later.

~~~bash
npm ci
npm run dev
~~~

The local development server runs at the URL printed by Astro.

## Before opening a pull request

Run:

~~~bash
npm run build
~~~

For visual changes, also run the screenshot utility against the local site and inspect desktop, tablet, and mobile output. Check reduced-motion behavior, keyboard navigation, image alternatives, and the browser console.

## Brand and client assets

- Preserve the approved Velune brand identity and verified content.
- Obtain permission before adding or publishing client names, photographs, videos, testimonials, or project material.
- Do not commit private source media, credentials, API keys, access tokens, or production environment files.
- Keep original media and generated web media clearly distinguished.
- Update alt text and project metadata when replacing visual assets.

There is currently no dedicated unit-test suite. Include screenshots and describe manual checks for visual changes.
